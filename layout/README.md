# Layout generator (Magic, SKY130A)

The whole layout is generated by script; nothing is drawn by hand.

| File | Role |
|---|---|
| `plan.py` → `plan.json` | Design plan from the v4b values: integer MOS units per branch, MIM capacitance per branch, resistor segmentation |
| `capblock2.py` | Network block: rows of W=10/L=10 nfet fingers (MOS capacitors) in gate-to-gate pairs with p-tap strips between pairs (latch-up rule LU.2), MIM tiles ≤ 30 × 30 µm stacked above per branch, met3 ground plane, met2 ground columns, per-branch met2 bus + via stack to the met4 sheet, and the 5-bit trim bank band (top plate = pin, one bottom-plate island per bit) |
| `resarray.py` | All 53 xhigh-poly stripes (0.83 µm pitch) in one guard ring; stripes ordered by height so every stripe top merges its urpm with a taller neighbour |
| `top.py` | Reads the TT 2×2 analog DEF, draws the power stripes, places both blocks (α = 0.5 mirrored), the resistor array, bank switches, standard cells (ties, buffers, antenna diodes) and all routing; writes GDS, LEF and the LVS extraction |
| `asbuilt.py` | Writes the as-built SPICE netlists (`sim/netlists`) from the plan and geometry; Xschem schematics are generated from these |
| `drcrep.tcl` | DRC summary in Magic with the full rule deck (`drc(full)`, same as the precheck) |
| `render.py`, `figlayout.py` | Layout picture and the labelled to-scale diagram (`docs/layout.png`) |

Build (needs Magic ≥ 8.3, open_pdks SKY130A, Python 3):

```
export PDK_ROOT=/path/to/pdk PDK=sky130A
mkdir -p layout_build && cd layout_build
python3 ../layout/top.py 4                      # writes top.tcl (stage 4 = full layout + LVS extraction)
bash ../layout/runmagic.sh . top.tcl top.log     # DRC summary at the end of top.log
cp tt_um_tjfreeborn1_cpe_a07a05.gds ../gds/ && cp lef/tt_um_tjfreeborn1_cpe_a07a05.lef ../lef/
python3 ../layout/asbuilt.py geo.json ../sim/netlists
```

The committed GDS was checked to be geometrically identical to a fresh build from these scripts.
